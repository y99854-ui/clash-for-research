# Clash for Research

面向科研的代理客户端：查文献、下载数据、写论文更顺手。基于 [Clash for Young](https://github.com/y99854-ui/clash-for-young) 和 mihomo 内核，Mac / Windows 免费使用。

A proxy client tuned for research: literature search, data downloads and writing. Based on [Clash for Young](https://github.com/y99854-ui/clash-for-young) and the mihomo core. Free for Mac and Windows.

## 下载 · Download

在 [Releases](https://github.com/y99854-ui/clash-for-research/releases/latest) 下载：
- Mac：`clash-for-research_..._universal.dmg`
- Windows：`clash-for-research_..._x64-setup.exe`

装好后软件会自动提示新版本，一键更新。
After installing, the app offers new versions itself, with one-click updates.

## 功能 · Features

- **学术网站预设 / Academic presets**：Google Scholar、arXiv、PubMed、Web of Science、各大出版社、GitHub、Hugging Face、Overleaf、Zotero……
- **我在校园网 / Campus switch**：出版社和数据库直连，用学校的订阅下载全文；Scholar 仍走代理。
- **稳定线路 / Stable line**：Scholar 和下载类网站固定一个节点，少人机验证，下载不断。
- **终端代理 / Terminal proxy**：连接时新终端自动走代理（git、pip、conda、Hugging Face），断开自动撤销。

源代码在 [clash-for-young](https://github.com/y99854-ui/clash-for-young) 仓库（同一套代码打包两个软件）。
Source code lives in the [clash-for-young](https://github.com/y99854-ui/clash-for-young) repo (one codebase, two apps).
